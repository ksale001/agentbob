agentbob privacy policy

Last updated: November 13, 2026

agentbob is a private assistant for a single household. Only that household's own Google account signs in to it.

What it accesses

With the account owner's permission, agentbob reads and organizes Gmail messages and reads and updates Google Calendar events for that one account.

How the data is used

The data is used only to help the household with its own email and calendar. It is not sold, shared with third parties, or used for advertising.

Where the data is kept

Data stays on the household's own computer. Google sign-in tokens are kept in that computer's secure keychain.

Removing access

The account owner can remove access at any time at https://myaccount.google.com/permissions.

Google API data

agentbob's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
